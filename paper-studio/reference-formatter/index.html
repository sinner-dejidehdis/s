Format your references for any journal.

Choose your target journal, paste DOIs or references, and get a verified list in that journal’s official style. Every entry is checked against Crossref first, so you never format a wrong reference.

Questions

Where do the styles come from?

From the Citation Style Language registry, the same styles Zotero and Mendeley use. Crossref formats each DOI in the journal’s style.

What if my reference has no DOI?

It is matched by title. If found, it is formatted in the closest standard style (APA, Vancouver or Chicago), and marked so.

Can I format in-text citations too?

Not yet. This tool formats the reference list.

Is it free?

Yes, with no sign-up.
