Arguo for Word

Check your paper without leaving Word.

A side panel in Word reads your manuscript, flags overclaiming, causal and vague wording, matches in-text citations to your reference list and checks every reference against Crossref. It can mark problems as Word comments. It never changes your text.

Download the add-in file Try the panel in your browser

Word on the web (Microsoft 365)

  1. Download the add-in file above.
  2. Open a document in Word on the web, then choose Home → Add-ins → More add-ins (or Insert → Add-ins).
  3. Choose My add-ins → Upload my add-in, select the downloaded file, then Upload.
  4. Click Check paper on the Home tab.

Word for Mac

  1. Quit Word. In Finder choose Go → Go to Folder… and open ~/Library/Containers/com.microsoft.Word/Data/Documents/wef (create the wef folder if it does not exist).
  2. Copy the downloaded add-in file into that folder.
  3. Open Word and a document, then choose Home → Add-ins (or Insert → My Add-ins) and pick Arguo under Developer add-ins.

Word for Windows

  1. Create a folder, for example C:\ArguoAddin, put the add-in file in it, then right-click the folder → Properties → Sharing → Share and copy its network path (for example \\YOUR-PC\ArguoAddin).
  2. In Word: File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs. Paste the network path, tick Show in Menu, then OK and restart Word.
  3. Choose Home → Add-ins → My Add-ins → Shared Folder and pick Arguo.

What it does, and does not do

  • Reads your document to check it; nothing is stored. Only “AI feedback on the selection” sends the selected text to our AI provider (Groq), which does not train on it.
  • Comments are added only when you choose Add as Word comments. Your sentences are never changed.
  • Literature search, the argument thread, journal styles and the submission checklist are in the full workspace.
