# 原型机方案（只做触感，不做力反馈）

目标：戴上原型，在网页里的 3D 模型（含网上的 glTF）上摸，根据**指尖和模型表面的位置关系**产生触感。

## 1. 路线

```
手指位置  ->  指尖 vs 模型表面  ->  接触量              ->  波形合成        ->  声道 -> 功放 -> 音圈执行器
(先鼠标,     (sim.js 射线探测)     (力代理/切向速度/材质)   (haptics.js)       (USB 多声道声卡)   (贴在指腹)
 后手部追踪)
```

选音频驱动是因为：音圈执行器本来就是音频器件，**不用写固件**，浏览器 Web Audio 直接出波形，纹理按“速度/材质”实时合成，改算法只改 JS。代价是延迟（见 §4）。

## 2. 已经做好的（软件，已测试）

| 部分 | 文件 | 状态 |
|---|---|---|
| 接触→波形（碰撞瞬态 + 滑动纹理，频率 = 速度/纹理周期） | `web/src/haptics.js` | 6 个单元测试通过 |
| 指尖与任意网格的位置关系（14 向射线，含线上 glTF） | `web/src/sim.js` | 端到端通过 |
| 音频输出（AudioWorklet，每指一个声道）+ WebSocket 备用输出 | `web/src/audio.js` | 在无头浏览器里能启动；**没接真实硬件** |
| 网页（场景、加载线上/本地模型、示波器、状态） | `web/index.html`、`web/src/app.js` | 端到端通过，默认链接真实 glb 加载并检测到接触 |

**想先做盲测（不需要手部追踪）：见 [QUICKSTART_TEST.md](QUICKSTART_TEST.md)。**

运行：`cd web && python3 -m http.server 8000`，浏览器开 `http://localhost:8000`，点“启动触觉输出”，鼠标移动指尖，滚轮降低高度压进物体并滑动。用 Chrome。

## 3. 还没有的 / 要你做的

**硬件（最小原型，单指）**
- 1 个宽带音圈执行器（研究常用 Haptuator 类，带宽约 10–1000 Hz，单价约 80–200 美元，见 [FEASIBILITY.md](FEASIBILITY.md) 同批来源；也可先用便宜的小型音圈/压电片做粗验证，**效果需实测**）。
- 1 路小功率音频功放 + USB 声卡（多指时需要多声道声卡，每指一路）。
- 指套/魔术贴把执行器压在指腹上，重量控制在约 10 g 以内。
- **安全**：功放输出串限流/保险，软件里已限幅在 ±1，但仍要在硬件上限制电流，防止线圈过热；先用最小音量。

**软件待做**
1. **手部追踪源**：现在用鼠标。下一步接真实手指位置，可选 WebXR 手部追踪（头显）或摄像头方案；注意单摄像头的深度不准，会直接影响“穿透深度”。接口很小：每帧给 `Fingertip.moveTo(位置mm, dt)`。
2. **多指**：`app.js` 的 `FINGERS` 增加手指，每指一个 `Fingertip` 和一个声道。
3. **材质标注**：线上模型的材质名常常识别不出，会落到默认“skin”。可在 glTF 里设 `userData.haptic`（`silk/fur/skin/wood/stone/metal`），或补一个“网格名→材质”的映射表。
4. **剪切模块**（Tier B）：本原型没有，抚摸方向感会弱，见 FEASIBILITY.md。

## 4. 已知限制（要老实面对）

- **延迟没有测过真实硬件**。浏览器音频输出的延迟取决于声卡和系统，无头测试里的 42 ms 不代表真机。要按实验 E4 用示波器测“指尖进入物体 → 执行器动作”，目标 < 20 ms；若音频路线达不到，改用 ESP32 + I2S（把 `WebSocketLink` 的 JSON 接到固件，固件里用同样的 `FingerVoice` 逻辑）。
- **“力”只是代理量**：没有力反馈，用穿透深度（3 mm ≈ 满值）推出，只影响振动幅度，没有真实压力感。
- **射线探测是近似**：很薄的面、尖角、模型内部会不准；大模型每帧 14 条射线会变慢，需要 BVH 加速。
- **波形参数没有人体实测**：纹理周期、幅度曲线都是起始值，要按 FEASIBILITY.md 的 E1–E3 对着真人调。

## 5. 里程碑（每步有判定标准）

| 步骤 | 做什么 | 判定标准 |
|---|---|---|
| M1 | 单指 + 鼠标，摸演示场景里 5 种材质 | 蒙眼被试能区分石头/丝绸/木头（≥ 8 人，正确率明显高于随机） |
| M2 | 测延迟（E4） | < 20 ms，否则换 ESP32 路线 |
| M3 | 换成真实手部追踪，摸线上 glTF | 指尖贴近表面时触感出现位置与视觉一致，用户不觉得“提前/滞后” |
| M4 | 加第二个手指（拇指） | 捏取物体时两指触感同步 |
| M5 | 做 E3（加剪切）决定是否做 Tier B | 见 FEASIBILITY.md |
