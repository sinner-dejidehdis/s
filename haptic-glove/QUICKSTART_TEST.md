# 简易测试版：今天就能做的盲测

目的：不依赖手部追踪、不依赖 3D 场景，先回答最关键的问题——**我合成的触感，人能不能分辨材质？** 这对应 FEASIBILITY.md 里的验证思路（M1）。

## 1. 启动

```bash
cd haptic-glove/web
python3 -m http.server 8000
# Chrome 打开 http://localhost:8000/test.html   （3D 沙盒是 index.html）
```

页面：启动输出 → 慢慢加音量 → “测试碰撞”确认有感觉 → 选材质和次数 → 开始盲测 → 下载 JSON。

## 2. 三档装置（从便宜到像样）

| 档 | 装置 | 能回答什么 | 局限 |
|---|---|---|---|
| 0 | 手指按在手机/笔记本扬声器格栅上 | 页面和音频链路通不通 | 小扬声器低频很弱，**不能用来判断触感好不好** |
| 1 | 电脑耳机口 → 一个小型 8Ω 扬声器或骨传导/激振片，用薄膜胶带固定在指腹 | 能粗测“是否可分辨” | 我没有测过具体型号。耳机口输出功率小，串一个几十欧的电阻限流；小扬声器在 40–100 Hz 很弱，结果会**偏悲观** |
| 2 | 宽带音圈执行器（Haptuator 类）+ 小功放 + USB 声卡 | 接近真实原型的结论 | 成本较高（单个执行器约 80–200 美元，见 FEASIBILITY.md 来源） |

先用 1 档跑通流程；1 档判断“不能分辨”时，不要直接下结论，要换 2 档确认。

## 3. 让结果可信的做法

1. **隔离声音**：执行器会发声，被试可能是“听”出来的而不是“摸”出来的。戴耳塞/耳罩，或耳机播放白噪声。
2. **遮住屏幕提示**：只靠触觉判断（页面有“闭眼”提示，但屏幕上的按钮名不影响刺激）。
3. **手指固定**：每次用同一根手指、同样的压紧程度；执行器和指腹之间只隔一层薄膜。
4. **至少 8 位受试者**，每人 4 种材质 × 5 次 = 20 题。
5. **判定**（页面已计算）：4 选 1 的随机水平是 25%；单人正确率 ≥ 60% 且 p < 0.01 算“能区分”；**≥ 8 人都达到**才算原型通过。
6. 保存每人的 JSON，看**混淆矩阵**：被混淆的两种材质就是要改参数的地方（`haptics.js` 里的 `MATERIALS`）。

## 4. 安全
- 总音量默认 0.1、软件硬上限 0.5；仍要在硬件上串限流电阻，**先小声再加**。
- 执行器或功放发烫、有异味、有异响：立刻拔线。
- 不要把功放输出直接接到不明器件上。

## 5. 测试结果怎么指导下一步
- **全部能区分**：进入 PROTOTYPE.md 的 M2（测延迟）和 M3（接手部追踪）。
- **部分材质混淆**：调这两种材质的纹理周期/粗糙度/硬度再测。
- **全部接近随机**：先排除装置问题（换 2 档、检查声音泄漏、检查接触压紧），确认后再考虑加剪切模块（FEASIBILITY.md 的 Tier B）。
