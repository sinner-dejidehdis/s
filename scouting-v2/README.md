# REBUILT Scout v2

第二版。代码全部自己写，没有复制其他队伍的代码、图片或队标。

借鉴的是 ScoutingPASS（FRC 2451）这类网页 scouting 工具的使用流程：
- 分页填写：Pre-match → Auto → Teleop → Endgame → Post-match → 二维码
- 字段由配置决定
- 可以在场地图上点选位置
- 计数器带 +1/+5/+10
- 二维码内容是制表符分隔的一行，能直接粘贴进表格

第一版在 `../scouting/`，没有改动。

## 页面

- **Match**：一名记录员盯一台机器人，按页面顺序填完后显示二维码。
  - 在 Settings 里导入赛程后，选好位置（Red 1 … Blue 3）队号会自动填。
  - 场地图点一下标记起始位置；Auto 和 Teleop 可以连续点，标记射球位置。
- **Pit**：机器参数，同样生成二维码。
- **Data**：负责人用。
  - 点进文本框，用 USB 扫码枪逐个扫码，每扫一个自动导入。
  - 队伍表格可以排序；点队号能看射球热力图、Pit 信息和备注。
  - 「Copy match data」复制带表头的 TSV，可以直接粘贴进 Google Sheets 或 Excel。
- **Settings**：赛程 CSV、场地图左右翻转。赛事代码由负责人统一设定，队员改不了（见下）。

## 新手说明（网页里自带）

- **每个问题下面都有一行提示**：写什么、怎么数、几分代表什么。熟练后可以在 Setup 页关掉「Show tips under each question」。
- **每页顶部有一句「这一段看什么」**（Auto 前 20 秒、Teleop、Endgame 最后 30 秒……）。
- **Guide 页**：第一次使用的步骤、每一页填什么、怎么交数据、1–5 分评分标准、负责人流程、排名怎么算（各项比例）、比赛术语解释。
- **第一次打开 Match 页**会出现欢迎卡片，引导去看 Guide；点「Got it」后不再出现。

## 自动排名（Rank 页）

- 每支队按所有场次的平均值计算。同一场如果有两名队员记了同一台机器人，先把两人的数字取平均，再参与总平均，所以每场只算一次。
- 自动分成两类：在至少 40% 的场次里打过防守，或平均每场防守 ≥ 20 秒的，算 **Defense robots**，其余算 **Offense robots**。这两个门槛在 `js/config.js` 的 `roles` 里改。
- **Fuel 改为 1–10 打分**（得分和丢失都是）：1 = 很少，10 = 很多，没有就选 None。各档的说明在 Guide 页的 Fuel scale。
- **进攻分（Offense index，0–100）**：每场 = 70% Fuel 得分（Auto 20% + Teleop 60% + Endgame 20% 加权的 1–10 评分）+ 30% 爬塔（Auto L1 + 结束时的 Tower 等级，满分 45 分）。队伍的进攻分是所有场次的平均。比例在 `js/config.js` 的 `offense` 里改。
- **命中率**：取队员赛后选的 Shooting accuracy 的平均（< 50% 按 35%，50–80% 按 65%，> 80% 按 90%）。
- **防守分**：防守评分占 50%、防守时长占 30%（每场 60 秒算满分）、可靠性占 20%，满分 100。
- 点排名里的任意一队，看它的详细数据：各项平均值、射球热力图、每场明细、Pit 信息和备注。

## 手机扫码

负责人在 Data 页点「Scan with phone camera」，对准队员屏幕上的二维码即可，批量二维码里的多场会一次全部导入。需要允许浏览器使用摄像头；在 claude.ai 链接里摄像头被禁用，请用离线文件或 GitHub Pages 版本。

## 一次交多场（批量二维码）

队员不用每场都去找负责人：
1. 队员打开 **Data** 页，在「Send records by QR」里选范围：**Not sent yet**（还没交的）、**All on this device**（本机全部）或 **Match range**（指定场次，比如 1–12）。
2. 点「Show QR codes for N records」，记录会自动分成几个二维码（每个大约 3 场），显示「QR 1 of 4」。
3. 负责人在自己设备的 Data 页点一下 Import 文本框，用扫码枪逐个扫；队员每扫完一个点「Next QR →」。用摄像头扫的话可以勾选自动翻页（每 2.5 秒一个）。
4. 全部扫完后，队员点「Done, all scanned」，这些记录会标记为已交，下次「Not sent yet」就不会再出现。

同一条记录重复扫不会重复计入，所以漏扫或多扫都没关系，重新显示再扫一遍即可。

## 离线使用

有两种方式，都不需要网络：

1. **下载离线文件**（推荐，最稳）
   - 在 Settings → Offline copy 点「Download offline file」；或者直接拷贝仓库里的 `rebuilt-scout-v2-offline.html`。
   - 这个文件包含整个应用，存到手机、平板或电脑上，用 Chrome / Edge 打开就能用，完全不联网。
   - 每次都从同一个位置打开同一个文件，记录才会留在这台设备上。
   - iPhone/iPad 在「文件」App 里直接预览不能运行，建议用方式 2。
2. **网页版加到主屏幕**
   - 用 GitHub Pages 地址联网打开一次，页面就会缓存下来，之后断网也能打开。
   - 用浏览器的「添加到主屏幕」，用起来像一个 App。

改了任何源文件后，要重新生成离线文件：`node scouting-v2/tools/build-offline.js`。测试会检查离线文件是不是最新的。另外要把 `sw.js` 里的 `VERSION` 加 1。

## 设定赛事（每场比赛前负责人做一次）

打开 `js/config.js`，改最上面的 `event: '2026test'`（用 TBA 的赛事代码，比如 `'2026txhou'`），然后：
1. 运行 `node scouting-v2/tools/build-offline.js` 重新生成离线文件；
2. 把 `sw.js` 里的 `VERSION` 加 1；
3. 推送 / 重新部署，再把新的离线文件发给队员。

所有队员的记录都会自动带上这个赛事代码，表单里不再有输入框。

## 场地图

选了位置（Red/Blue）之后，场地图会按联盟变化：红方区域是红色，蓝方的图旋转 180°（从看台看过去，蓝方那头就是红方那头转了 180°），Outpost 和 Depot 会跟着换位置。坐在场地另一侧时，打开 Settings 里的「Flip the field map」。保存的坐标统一按「该机器人自己联盟那头」记录，所以红蓝两边的数据可以画在同一张热力图上。

## 改字段

只改 `js/config.js` 就行。每个字段的 `code` 就是导出时的列；列的顺序按配置里的顺序。

注意：改了字段，旧版本生成的二维码就读不进来了，因为列数会对不上。
