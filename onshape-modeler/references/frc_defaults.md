# FRC 常用默认值（英制，单位 in）

| 项目 | 默认 |
|---|---|
| 侧板材料厚度 | 0.25（1/4" 铝板）；轻量化可用 0.125 |
| 滚轮直径 | 2.0（compliant wheel / 管件滚轮常见 2"） |
| 轴径 | 0.5（1/2" 六角轴 / 圆轴）；3/8" = 0.375 |
| 轴伸出侧板外 | 0.5 |
| 滚轮端面间隙 | 0.0625 |
| 机器框架内宽 | 24–27（bumper 内约 26–28 总宽，intake 内宽 ≤ 26） |
| 枢轴孔 | Ø0.5，位于原点 |
| 孔间隙 | 直径 +0.016 |
| 常见 intake 滚轮数 | over-bumper 2–3 个，沿斜线逐级升高，前低后高 |
