# 历年夺冠队伍设计调研（用于 intake / shooter 模板）

只记录能在**原始资料**里读到的数字。冠军联盟的成员名单，几个搜索来源的写法互相不一致，**没有核实**，所以这里不列联盟名单，
只引用队伍自己公开的技术手册和 frcdesign.org 的示例。已核实一致的：2025 冠军联盟是 2910、1323、5026、4272
（[2910 的赛季回顾](https://frcteam2910.org/2025/05/07/2025-recap-post/)）。254 在 2017 年手册的发布说明里自称世界冠军机器人 Misfire。

## 资料与数据

### 254 · 2017（Steamworks）技术手册 — <https://media.team254.com/2017/09/964207d8-technicalBinder2017.pdf>
- Shooter：**双背旋飞轮**（单轮 + 固定 hood），4 个 4" Fairlane 轮，4 个 775 Pro、4:1 皮带减速，**轮速 3500 rpm**
  （4" 轮面速约 733 in/s），**固定 hood 14°**，**"0.5\" foam provides optimal compression"**（球约 5.5"，压缩约 9%），
  激光切割侧板；平均 15 fuel/s、85% 命中。原型测试里背旋飞轮"准、吞吐高、好封装"，无旋/双皮带方案不准。
- 搜索摘要还提到钢飞轮约 4 lb·in² 转动惯量、hood 贴聚氨酯条提高压缩和抓力（来自 254 官网/Chief Delphi 的摘要，手册正文里我只确认了压缩量和轮速）。
- Intake：全宽、**表面速度大于车速**（原型 40 ft/s）、聚碳酸酯侧板、斜坡（60°、平均 0.2" 压缩）。

### 254 · 2022（Rapid React）技术手册 — <https://media.team254.com/2022/10/8f2407a5-Team_254_Tech_Binder_2022.pdf>
- Intake：**过保险杠、全宽（30"）**，水平辊装在**气动四连杆**上（3/4" 缸径、2" 行程气缸）；**1/4" 聚碳酸酯侧板**
  （"robust and compliant to impacts"）；**1 个 Falcon 带 2 个皮带驱动的辊**：3" OD、1/16" 壁聚碳酸酯管加防滑带
  （2.4:1），1" OD、0.3" 壁铝管加热缩管（1.6:1）把球推入送球器。
- Shooter：目标"大量抓力、包角（加速时间）、可调 hood"。**9" 铝飞轮，14:72T 减速；5 个 1.75" 3D 打印后辊，1:1；
  都用 2 个 Falcon 带动并包防滑带；直径和减速比按电机峰值功率点选，并让轮面速度匹配使球无后旋（减少弹出）**；
  hood 行程 35°，单个 Falcon 经 16:52 皮带、14:42 齿轮、14:510 3D 打印扇形齿轮驱动。
- Elevator（对照）：2x1x1/16" 铝管立柱和 carriage，#25 链条加花篮螺栓张紧，1 个 Falcon、41:1。

### 1678 · 2022 shooter — <https://frcdesign.org/mechanism-examples/shooter/1678_2022_shooter/>
- 集成 hood 式 shooter + indexer，**2 个 SDS 飞轮，靠质量保持射击中转速恒定**；背辊反向旋转控制后旋；
  hood 用 3D 打印齿条 + 小齿轮精确调角。页面没有给出电机、传动比、压缩量等数值。

## 我据此改了什么

| 证据 | 修改 |
|---|---|
| 254 2017：压缩 0.5"（约 9%）最优 | shooter 默认 `compression` 0.75" → **0.5"**（5.9" 球约 8.5%）；9.5" 球等其他球径需自行调 |
| 254 2017：轮面速 ≈ 733 in/s；2022：9" 轮约 585 in/s | 保留 12T→24T（空载 3000 rpm、4" 轮 628 in/s），与冠军队伍同量级；信息里给出轮速 |
| 254 2017 / 1678 2022：飞轮要有质量；2017 钢飞轮约 4 lb·in² | 新增每侧 **1 个钢质惯量盘**（Ø3.5" x 0.5"）；总惯量约 6.5 lb·in²（`inertia_discs=0` 关闭） |
| 254 2017：hood 贴聚氨酯条提高压缩和抓力 | 新增 **hood 聚氨酯条**（`hood_strip`，默认 1/16"，宽 1" 对准每个飞轮） |
| 254 早期 20°→45° 切线 hood、2017 固定 14°、2022 可调 35° 行程 | 默认发射角 60° → **45°**（`hood_end=315`）；可调 hood 未实现 |
| 254 2022：1/4" 聚碳酸酯侧板 | intake 侧板默认 **聚碳酸酯**（`plate_material`，几何不变，BOM/DXF 材料随之变化）；轴承压入塑料板 |
| 254 2022：前辊 3" PC 管抓球、后辊小 | intake `roller_diameters` 默认 **[3, 2, 2]**，球检查支持不同半径 |
| 254 2017/2022：intake 面速要大于车速（40 / ~35 ft/s） | 前辊空载面速 39 ft/s、后辊 26 ft/s；低于 15 ft/s 时模板打印警告 |
| 254 2022 四连杆、1678 2024 slapdown：intake 绕枢轴动 | 新增 **枢轴**（hex 轴 + 两个法兰轴承，在最后一个滚轮后面）；气缸/四连杆臂未做 |

## 没采用的（以及原因）
- **后辊（254 2022，5 个 1.75" 辊，面速匹配无后旋）**：需要多根轴和传动，下一步；目前 hood 加聚氨酯条是固定摩擦面，球会有后旋。
- **可调 hood（扇形齿轮 + 电机）**、**四连杆气动 intake**、**送球器/serializer**：`cots.json` 里没有气缸、齿轮等标准件，且需要 API 才能查到新的 MKCad 零件；先不做。
- **更大飞轮（9"）/ 升速传动**：`cots.json` 只有 Falcon 孔的 12T 带轮，无法做升速；用 `wheel_diameter` 加大轮径提高面速。
