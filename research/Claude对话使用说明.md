# 在 Claude 对话（claude.ai）里继续做深度档案

## 一、建一个项目（推荐）
1. 在 claude.ai 左侧点"项目"，新建一个项目，名字比如"漫剧选题研究"。
2. **项目知识**：只上传下面 2 个小文件，给每本书的分析腾出上下文空间。
   - `00-工作总结与成果汇总.md`：总览和横向规律；
   - `01-回家上坟，把鬼帝祖宗们哭醒了.md`：样板档案，后面每本都照它的格式写。
   - （可选）`02-神通者.md`、`03-慈航市.md`，作为另外两种类型的样板。
3. **项目指令**：把下面整段粘贴进去。

```
你是漫剧（AI动画短剧）改编的选题分析师。我会每次上传一本番茄网文的"深读素材"txt，素材里依次有：
1. 第一行的 JSON 统计数据（字数、章节数、单章长度、对白占比十段曲线、台词长度和问号/叹号比例、常用说话动词、章末收尾方式、人物出场统计、标题特征）；
2. 全部章节标题；
3. 前 12 章全文；
4. 若干转折章的开头部分；
5. 最后 2 章全文。

请严格按项目知识里 01 号样板的格式和细致程度，写这本书的深度档案，包含：
一、基本信息与数据卡（用素材里的统计数据，并写出数据解读）
二、核心设定 / 金手指机制
三、人物表（首次出场章、身份与作用。人物统计里混有"不知""一道"这类噪音词，要剔除）
四、黄金章节逐章表：每章写剧情节拍、手法、章末钩子
五、全书分段大纲（根据全部标题和抽读的章节推断，并注明是推断）
六、结构分析
七、节奏分析（结合十段数据）
八、对话分析（只分析写法；示例台词必须是原创的，并标注"原创示例"）
九、行业信号（流量、授权、风险）
十、漫剧第一季 10–12 集分集方案，加合规改写清单

要求：
- 全部用自己的话概括，不大段摘录原文；
- 不用节省篇幅，尽量细致；
- 最后附一行打分（1–5 分）：开局钩子、单元结构、视觉奇观、合规风险（分越高越安全）、授权可得性（分越高越好拿）、综合推荐度。
```

## 二、每本书怎么发
在项目里每本书开一个**新对话**，上传对应的素材 txt，然后发送：

```
这是第 NN 本《书名》的深读素材，请按项目指令写深度档案。
```

写完后，把回答复制保存成 `NN-书名.md`。一个对话只做一本，避免上下文溢出。

## 四、全部做完之后
新开一个对话，把 35 份档案都上传（如果太多，就上传每份档案最后的打分行和一句话结论），然后发送：

```
请汇总这 35 份档案：
1. 更新横向规律（题材、金手指、开篇公式、节奏、对话）；
2. 按打分做一张"漫剧改编价值排行"总表；
3. 给出前 5 名的立项建议和风险。
```

## 五、注意
素材包里是小说原文的节选，只供你自己分析使用，**不要公开分享，也不要传到公开仓库**。
