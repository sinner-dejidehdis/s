# v6：规模升级 · 升级可视化 · 暴富与地位 · 世界独立运行

在 `爆款化版/` 五份剧本之上，给每部加了一份“加强层”，不改人物与主线，只把四件事做成**可数、可拍、可复查**的体系。每份都含：规模阶梯表、常驻 HUD 与结算卡、逐集账本、前后态度对照、地位仪式、榜单、世界独立运行（世界事件日历、势力议程、主角缺席测试、速报栏）、24 集整合表、第 1 集的 HUD 示例。

## 四个系统怎么落实
| 要求 | 落实方式 |
|---|---|
| 规模升级 | 每卷一张新地图、一个数量级：钱、人、地盘、敌人同步放大，有数字阶梯表 |
| 升级可视化 | 常驻 HUD、每集 3 秒结算卡、外观四段变化、能力树；每部有一个专属的可视化主物件 |
| 暴富、地位爽感 | 逐集账本、称谓牌、前后态度对照表、每卷一场地位仪式、榜单名次滚动 |
| 世界独立运行 | 每部有一条**不受主角控制的世界指标**、世界事件日历（标注主角是否在场）、势力议程表、“主角缺席”测试、每集开头速报栏 |

## 各部的专属元素
| 作品 | 专属可视化物件 | 独立于主角的世界指标 |
|---|---|---|
| 子时当铺 | 当铺外观四段变化、净资产条、青灯 | 运价指数、城运债到期日、对手收购日程 |
| 补天匠 | 针脚图鉴墙、境界光环 | **天幕完整度**（自己衰减，主角只改斜率） |
| 裁云记 | 缝纫机计数器、订单地图 | 政策日历（布票作废、承包制）、原料价格、陆峥的部队调防 |
| 守则修订员 | 词典墙、红笔颜色、危险等级 | **守则生长率**（每天自己长出新守则） |
| 辩世 | 官服变色、朝堂势力图 | **世界倾向条**（既定↔多元）、朝堂议程日历 |
