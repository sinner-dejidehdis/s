# 爆款化版：说明与新旧对照

## 做了什么
按你的要求，不考虑审核，全力贴近热门小说的风格和剧情，把五部剧本各自重写了一个“爆款化版”。旧版（v4 及《辩世》v1）原样保留，没有被覆盖。

## 五部共同的改动（对应 35 本热门的横向规律）
| 改动 | 对应热门做法 |
|---|---|
| 集标题改为“爽点即标题”，长标题带感叹号 | 十年阳寿、修机甲的标题风格 |
| 金手指第 1 集亮相，第 3 集内完成第一次逆转 | 35 本里金手指平均在第 2–4 章生效 |
| 加外显面板和升级阶梯，每集有“获得” | 十年阳寿、修机甲、斩神 |
| 主角改为嚣张、毒舌、有梗，每部 3–4 句语录 | 时停（比无限回档阅读量高近 4 倍） |
| 加暴富、官阶、地位的暴涨 | 十年阳寿、修机甲、七猫男频 |
| 加打脸排队和反派梯队 | 热门“一章一个打脸对象” |
| 加班底、背书链 | 修机甲的“女儿加父亲” |
| 加掉马与脑补：全场以为主角是大人物 | 别装了、时停 |
| 加地图式扩张，四卷四张地图 | 慈航市、斩神 |
| 加暧昧、美人环绕、契约夫妻、血腥死法 | 热门里常见的“佐料” |
| 暗线保留并闭环 | 无限回档的首尾闭环 |

## 五部各自的核心变化
| 作品 | 旧版 | 爆款化版 |
|---|---|---|
| 子时当铺 | 惩恶加情感，规模只有一间铺 | 买穷人、卖富人，当铺升级到天下当铺，班底流，从外卖员打到京城 |
| 补天匠 | 只会拆、不获得 | 拆解即收集（针脚图鉴），开拆线铺，修机甲式的顾客单元，背书链 |
| 裁云记 | 事业线为主，男主是搭档 | 替嫁随军，契约夫妻，强势宠妻男主，龙凤胎，前夫追妻火葬场 |
| 守则修订员 | 只失去，不获得 | 失词换词权，死亡抵命回档，血腥死法，论坛脑补“笔神”，一个世界一季 |
| 辩世 | 主角前期没有金手指 | 第 1 集绑定辩录系统，官阶一路到摄政，首辅拉拢，美人环绕，打脸权贵 |

## 内容边界
我保留了热门里常见的暧昧、擦边氛围、血腥死法和对立面的强烈打脸，但没有写露骨的性描写，也没有把未成年人写成性暗示对象，没有出现对真实民族或国家的贬损。需要更极端的版本，请告诉我具体方向。
