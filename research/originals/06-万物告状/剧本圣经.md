## 一、钩子

**一句话（对外）**：宗门被压到百宗榜倒数第一，五岁的小师妹能听懂万物说话——灵草告状说被偷了，烧火棍哭着说自己是神剑，桌子揭发内鬼，七个字都不用说，满山灵物替她把天下赢了回来。

**十字钩**：*听万物告状的小师妹。*

**第一眼画面**：钱庄账房捧着地契上门，所有大人都装死，五岁小姑娘蹲在灶台前，侧着耳朵：“它说……它是剑。”

### 观众承诺
1. **爽**：每集一次“灵物当众告状 → 对手翻车”；
2. **萌 + 反差**：五个装废物的师兄，被小师妹一句话揭穿，全员“护崽狂魔”；
3. **悬**：十年前这座宗门为什么一夜败落？内鬼是谁？
4. **泪**：龟爷之死 + 内鬼被原谅。

## 二、世界观（开放、能一直长大）

### 1. 九州与百宗榜
- 九州修仙界有一张**百宗榜**，由“榜阁”每年评一次，榜单决定灵脉分配、坊市税率、秘境名额。
- **玄天宗**十年前是榜首，一夜败落，如今是榜单倒数第一（第一百名）。
- **保级规则**（先于主角存在的日程）：连续三年排名末位的宗门，由榜阁“摘牌”，山门收归榜阁。**今年是第三年，距摘牌还有九十日**。
- 山门地契已被抵押给“万宝钱庄”，到期还不上钱，钱庄先收山。

### 2. 灵物与“听山”
- 世上凡有灵性之物（草木、刀剑、灵兽、器物、山石）都有微弱意识，但**普通修士听不见**。
- 小满的“听山”规则（第一季严格执行）：
  1. 只听得懂有灵性的东西；
  2. 灵物各有脾气和口音：老桌子絮叨、灵草爱告状、剑傲娇、灵兽爱吹牛；**它们会夸大、会撒谎、会偏心**，不能全信，要交叉验证（推理乐趣）；
  3. **灵物开口，必须被“回话”**：小满得答应它一件小事，这些“承诺”会累积，是后期“万物还情”的伏笔；
  4. **公开限制**：人多、被高阶威压、或在“榜阁”这类有禁制的场所，灵物会噤声；
  5. **代价**：听久了会犯困、耳鸣，一次听太多会睡过去（可爱，也是危险）。
- **配音卖点（可选）**：不同灵物用不同口音或腔调，作为配音设计，不是剧情依赖。*相似风险*：已有热门团宠漫剧以方言为卖点，需要差异化处理（待验证）。

### 3. 势力与议程（不围着主角转）
| 势力 | 议程 |
|---|---|
| 万宝钱庄 | 收山卖地；背后还有人要玄天宗后山的“东西” |
| 青云宗 | 邻宗，榜单前十，想吞并玄天宗灵脉；少主顾长离既骄傲又有底线 |
| 榜阁 | 评榜机构，执事殿执事严守规则，也会被收买 |
| 天机阁 | 十年前灭宗真凶（第二季后半才浮出，前期只留“被擦掉的名字”这类痕迹） |

## 三、人物

### 主角：乔小满（五岁）
- 外表软萌，嘴甜，爱说“它说……”；
- **说谎会咬舌头**（不会撒谎），是最大喜剧点，也让她成为“真话机器”；
- 怕黑，怕一个人睡；
- 目标：留下这个家；
- 成长：从“被保护的小孩”到“让万物为她站台”的小宗主。

### 五位师兄（每个人都在装废物）
| 师兄 | 表面 | 真实 | 秘密 | 与小满的关系 |
|---|---|---|---|---|
| 大师兄 沈惊澜 | 洗碗烧火的懒汉 | 十年前的剑道天才，本命剑被封，藏在灶台的烧火棍里 | 他怕再握剑，因为十年前那一夜他没能拔剑 | 第一个被小满“戳破”的人 |
| 二师兄 白昼 | 摆摊算命的神棍 | 魔宗遗孤（魔宗少主），靠玄天宗庇护活下来 | 魔气失控会伤人，小满的声音能安抚 | 睡前故事讲得最好的人 |
| 三师兄 药无忧 | 药罐子，天天试药 | 丹道圣手，尝不出味道，把所有药自己试 | 他的失味与十年前那夜的毒有关 | 给小满做不苦的药 |
| 四师兄 石三 | 木讷的修补匠 | 每天补“漏雨的山门”，其实在**独自撑着整座护山大阵** | 阵眼一旦松手，宗门当夜就被攻破 | 最不会说话，却最先学会抱小满 |
| 五师兄 柳折枝 | 爱美、爱赌、欠债最多 | 为还钱庄的债，**偷偷把宗门情报卖给钱庄**，内鬼 | 他被人拿住软肋，不是坏人 | 小满最亲的哥哥，也是第一季最痛的刀 |

### 其他
- **龟爷**：守山灵龟，千岁，口头禅“老夫当年……”，是唯一完整记得十年前那夜的活物；**第一季情感高点：寿尽而终，把“那夜”的片段留给小满**。
- **宗主 乔慎**（小满养父）：十年前失踪，只留下一枚“不要信账本”的玉简；第二季后半回归。
- **顾长离**（青云宗少主）：对手 → 对头 → 盟友。有一次公开认错戏。
- **钱不空**（钱庄账房）：第一个反派，嘴硬胆小，后期被收编成“反派喜剧担当”。

## 四、主线结构（不限集数，按“赛段”走）

### 总弧
**保住山门（90 日）→ 揭开内鬼 → 重回百宗榜前列 → 揭开十年前的真凶 → 宗主归来 / 新宗主。**

### 第一季（保级季）：九十日倒计时
| 阶段 | 目标 | 主要戏 | 大事件 | 情绪 |
|---|---|---|---|---|
| A 山门最后一天 | 活过今天 | 钱庄收地契；烧火棍是神剑；小满第一次当众“翻译” | 宽限九十日 | 笑 |
| B 拼装保级班底 | 凑够保级赛资格 | 每位师兄的秘密一件件被小满“听”出来；护山大阵漏雨；后山枯井里的灵泉 | 登记“镇山灵物”：龟爷出场 | 暖 |
| C 第一场外战 | 赢第一场排位赛 | 对手青云宗用作弊灵兽，被灵兽自己告状；小满当众不能说谎 | 排位 +30 名 | 爽 |
| D 内鬼线 | 找出泄密者 | 桌子、账本、狗告状；线索指向五师兄；全宗沉默 | 五师兄坦白，被原谅 | 痛→暖 |

### 第二季（登榜季）与第三季（真凶季）
只写方向：二季师兄们的身份一个个显露，玄天宗从榜尾冲进前十，天机阁出现；三季回收十年前真相，宗主归来，小满成为新的宗主，“万物还情”爆发。

## 五、爆款设计检查（逐条对应前面的分析）

| 要素 | 本剧如何做 |
|---|---|
| 一句话钩子 | 见上，“听万物告状的小师妹” |
| 金手指有成本、有公开限制 | 回话、噤声、犯困、会撒谎的灵物 |
| 先于主角的世界日程 | 百宗榜摘牌九十日、钱庄抵押、十年前旧案 |
| 被动入局 | 小满不是被选中，是被留在一座快倒的山上 |
| 可见收益 | 排名、灵物数量、师兄们的“真身”解封 |
| 一次死别 | 龟爷（前面有 10+ 段铺垫） |
| 反派阶梯 | 账房 → 邻宗少主 → 榜阁执事 → 天机阁 |
| 重复套路但有变化 | “灵物告状 → 对手翻车”，每次告状角度不同：证物、证人、证言、反证、沉默 |
| 配角各有目的 | 五位师兄、龟爷、顾长离都有自己的秘密和选择 |
| 团宠情感 | 五位师兄的反差“护崽”，每集至少一个小满被抱起的画面 |

## 六、风险与待验证
1. **相似风险**：榜单上已有“团宠小师妹”“师兄们慌了”类热门漫剧。本剧用“万物告状 + 师兄们装废物 + 内鬼线”区分，但是否足够差异化，**没有数据，待验证**。
2. **五岁主角**的台词与“真话”设定，需要配音和审查把握分寸。
3. **内鬼是五师兄**：是否会让观众难以接受，建议先做小测试。
4. **相同点**：宗门倒闭、团宠、师兄，是题材共性，不是抄袭；但需法务/平台核对。
5. 评审模拟不是真实观众反应。
6. 合规：未成年人主角、战斗/死亡描写（龟爷之死）要温和处理；AI 生成需按平台要求标注。
