# 《全修仙界都来找我告状：五岁小师妹一锤定案》剧本圣经（v2 · 差异化版）

> 题材：东方玄幻 · 师门团宠 · 断案爽剧 · 竖屏漫剧 ｜ 目标品类：红果漫剧榜的“团宠师门 / 萌宝修真 / 系统金手指”
> v1 → v2 的原因：红果漫剧热播榜（10 月 13 日）已有《乡下来的掌上明珠》（能与小动物沟通，第 12、40 名）、《深山护林》（听懂动物心声，第 100 名），团宠师门另有《咱家剑宗团宠小师妹》《糯糯下山》《一梦青玄》《睡醒三百年》。v1 的“只有她听得见万物说话”会被看成换皮。
> v2 的做法：**保留已被验证的优点**（团宠、师兄反差、萌宝、宗门保级、可见收益），**只换核心**：从“她听得见”改成“她能开堂，物证当众开口，判决由天道执行”，并加一层主角身份反转。
> 声明：人物、设定、情节均为原创。**不保证爆火**；下文判断是结构推测，没有观众数据，评审团也是 AI 模拟。

旧版（v1）保存在 git 历史里。

## 一、钩子

**一句话**：五岁的小师妹一拍惊堂木，满山的剑、草、桌椅、地契都能当众开口作证；她判谁欠了，天道就让谁当场还——全修仙界的冤屈都来找她告状，而她自己，就是十年前被偷走的那块惊堂木。

**十字钩**：*小师妹一锤，万物开口作证。*

**第一眼画面（前 5 秒）**：钱庄账房把地契拍在桌上，五个师兄全在装死。五岁小姑娘踮脚爬上凳子，抡起一块比她手还大的木头，“啪”——
满院的东西同时睁开了眼睛。地契在桌上发抖：“我……我被人改过字。”

### 和榜上同类的区别（一眼能看出来的）
| 已上榜作品的做法 | 本剧的做法 |
|---|---|
| 只有主角听得见动物心声，靠主角转述 | **升堂后所有人都听得见**，物证当众开口，反派当场社死 |
| 能力是“沟通”，结果靠主角去说服 | 能力是“判决”，**判了就生效**（东西当场还回去、假契当场烧掉） |
| 对象是动物、萌宠 | 对象是**万物**，主力是器物：地契、账本、秤、剑、门、印章、丹炉 |
| 团宠的理由是主角可爱 | 团宠的理由有两层：可爱，加上**她是全天下都在找的宝物**，师兄们装废物是为了藏她 |
| 系统面板 | **“人情簿”**：每结一案，万物欠她一份情，簿上多一行，可以在大场面里一次“催还” |

### 观众承诺
1. **爽**：一集一案，“升堂 → 物证开口 → 反派当众翻车 → 天道执行”，对应榜上最强的“一单一集”结构；
2. **萌 + 反差**：五岁法官、奶声奶气的“升堂！”，五个装废物的大佬师兄当衙役；
3. **悬**：十年前宗门为什么一夜败落？惊堂木为什么会变成一个孩子？
4. **泪**：她每判一案，手心多一圈木头年轮，判到最后会不会变回一块木头。

## 二、核心设定：万物公堂

### 1. 规则（第一季严格执行，写进第 1 集画面里）
1. **递状**：受了委屈的物（器物、草木、灵兽、山石）会向小满“递状”，画面上是一张从物体里飘出来的小纸条，只有她看得见。不升堂时，她只能听见零碎的哭声。
2. **升堂**：她拍惊堂木喊“升堂”，**方圆十丈内所有人都能听见物证说话**。这是本剧和“听懂动物心声”最大的区别，也是爽点来源。
3. **物会撒谎**：物有脾气、会偏心、会夸大。小满要问、要对质；**升堂后作伪证的物会裂开**（视觉奇观，也是推理钩子：谁裂了谁在说谎）。
4. **判决只判“还”**：她只能判“欠了什么、还回去”（被偷的灵气回到原主、伪造的契约烧掉、被冒名的功劳物归原主），**不能判人生死**。这让爽点干净，五岁主角也合规。
5. **天道执行**：判决当场生效，围观者都看得见（金光、东西飞回去、字迹褪色）。
6. **判错反噬**：判错了，判决反弹到她自己身上。所以她必须查清楚，推理不是装饰。
7. **代价**：每开一次堂，她右手心多一圈木纹年轮。她怕疼，更怕被师兄们发现。

### 2. 人情簿（可见收益，对应榜上的“系统”偏好）
- 每结一案，原告（物）欠她一份情，簿上自动多一行：“玄天宗灶台烧火棍，欠小满一次”。
- 情可以“催还”：关键时刻她翻开人情簿喊一声，欠她情的物一起出手。
- 第一季簿上的条数是贯穿的数字目标（第 1 集 1 条 → 第一季末 300 条），保级决赛靠一次“全簿催还”翻盘。

### 3. 世界：九州与百宗榜（沿用 v1）
- **百宗榜**由“榜阁”每年评一次，决定灵脉、税率、秘境名额。玄天宗十年前是榜首，一夜败落，现在第一百名。
- **保级规则**：连续三年垫底，榜阁“摘牌”收山。今年第三年，**距摘牌九十日**。山门地契抵押给“万宝钱庄”。
- **公堂失传**：九州古时有“万物公堂”，由一块会说话的惊堂木主持，三百年前失传。各大势力都在找它。

### 4. 势力与议程（不围着主角转）
| 势力 | 议程 |
|---|---|
| 万宝钱庄 | 收山卖地；背后的东家要的是玄天宗后山“镇着的东西” |
| 青云宗 | 榜单前十，想吞玄天宗灵脉；少主顾长离骄傲但守规矩 |
| 榜阁 | 评榜机构，执事殿执事守规则，也会被收买 |
| 天机阁 | 十年前夜袭玄天宗、要夺惊堂木的真凶（第二季后半浮出，前期只留“被擦掉的名字”） |

## 三、人物

### 主角：乔小满（看起来五岁）
- 外表软萌，奶凶，拍惊堂木要踮脚；口头禅“它说……”“升堂！”
- **说谎会咬舌头**：v1 只是喜剧点，v2 给了原因：惊堂木不能说假话。
- 怕黑、怕一个人睡、怕手心的年轮被看见。
- **身份（第一季第 E 段揭开）**：她不是捡来的孩子，是十年前那一夜，宗主乔慎为了不让惊堂木落到天机阁手里，**用自己一半修为把它炼成了一个孩子**。她能听见万物，是因为她本来就是“物”。
- **灵魂**：最会替万物讨公道的，自己就是一件被当成孩子养大的东西。她的问题是：“我是物，还是人？”第一季的答案由师兄们给出：你是我们的小师妹。
- 成长：从“被保护的小孩”到“替天下物件讨公道的小宗主”。

### 五位师兄（每个人都在装废物，都在藏她）
| 师兄 | 表面 | 真实 | 秘密 | 与小满 |
|---|---|---|---|---|
| 大师兄 沈惊澜 | 洗碗烧火的懒汉 | 十年前的剑道天才，本命剑被封进灶台的烧火棍 | 那一夜他没能拔剑；**他知道小满是什么，发誓再也不让人碰她** | 第一个被戳破，也是第一个当她“衙役”的人 |
| 二师兄 白昼 | 摆摊算命的神棍 | 魔宗遗孤，靠玄天宗庇护活下来 | 魔气失控会伤人，惊堂木的声音能镇住他 | 睡前故事讲得最好 |
| 三师兄 药无忧 | 药罐子，天天试药 | 丹道圣手，尝不出味道 | 失味和那夜的毒有关；**他每晚偷偷给小满手心的年轮涂药，假装是冻疮膏** | 最早发现年轮的人 |
| 四师兄 石三 | 木讷的修补匠 | 独自撑着整座护山大阵 | 他一松手，宗门当夜被破 | 最不会说话，最先学会抱她 |
| 五师兄 柳折枝 | 爱美、爱赌、欠债最多 | 为还钱庄的债，把宗门情报卖给钱庄 | 被人拿住软肋（妹妹的医药费由钱庄医馆垫付，利息被同一支笔改过）；**他卖的不是账本，是“小满是什么”这个消息** | 小满最亲的哥哥，第一季最痛的一刀 |

**团宠的层次**：表层是宠一个孩子；里层是一群废物在藏一件全天下都在找的宝物；最里层是他们明知她是“物”，仍然只把她当妹妹。

### 其他
- **龟爷**：守山灵龟，千岁，唯一完整记得那一夜的活物。第一季泪点：寿尽前把最后一份“状”递给小满，状告的是自己——“那一夜，我没能护住宗主”，请她判。小满判：“不欠。”
- **宗主 乔慎**：失踪，只留一枚“不要信账本”的玉简。第二季后半回归，修为只剩一半（都给了她）。
- **顾长离**：对手 → 对头 → 盟友。第 3 集被判输后公开认错。
- **钱不空**：钱庄账房，第一个反派，嘴硬胆小，后来被收编为“喜剧担当”，给公堂当书吏。

## 五、主线结构（不限集数，按赛段）

### 总弧
保住山门（90 日）→ 揭开内鬼 → 揭开“小满是什么” → 重回百宗榜前列 → 十年前真凶 → 宗主归来。

### 第一季（保级季）
| 阶段 | 目标 | 主要案子 | 大事件 | 情绪 |
|---|---|---|---|---|
| A 山门最后一天 | 活过今天 | 地契翻供、琉璃算盘裂开 | 利息作废，本金三万灵石宽限九十日；抵押条款“门内一切器物”是天机阁埋的钩子（小满是物，也在抵押里）；天机阁察觉“惊堂木醒了” | 笑、爽 |
| B 拼装班底 | 凑保级赛资格 | 烧火棍认主、石壁递状、枯井灵泉 | 师兄们的秘密一件件被开堂“审”出来；龟爷登记为镇山灵物 | 暖 |
| C 第一场外战 | 赢第一场排位赛 | 青云宗作弊灵兽的蹄铁当众开口 | 排位 +30；顾长离认错 | 爽 |
| D 内鬼线 | 找出泄密者 | 账本沉默、桌子告状、脚印 | 五师兄坦白：他卖的是“小满是什么”；被原谅 | 痛 → 暖 |
| E 身份揭开 | 守住阵眼 | 天机阁派人来“认领失物” | 小满知道自己是惊堂木；龟爷状告自己后寿尽；师兄们：“我们不交” | 泪 |
| F 保级决赛 | 保住山门 | 在榜阁禁制里开不了堂 | 全簿催还：三百件欠她情的物一起作证；保级进前五十；榜上“被擦掉的名字” | 燃 |

### 第二季（登榜季）与第三季（真凶季）
二季：公堂名声传开，九州各地的物件千里递状，换地图巡回断案；师兄们身份一个个显露；顾长离成为盟友。三季：被擦掉的名字是谁，天机阁要惊堂木做什么（审判天道本身），宗主归来，小满选择做人还是做物。

## 六、爆款设计检查
| 要素 | 本剧如何做 |
|---|---|
| 一句话钩子 | “小师妹一锤，万物开口作证” |
| 已验证优点保留 | 团宠、师兄反差、萌宝、宗门保级倒计时、可见收益 |
| 核心差异 | 公开升堂（人人听得见）+ 判决生效 + 主角就是物 |
| 金手指有成本 | 判错反噬、年轮、禁制场所开不了堂、物会撒谎 |
| 先于主角的世界日程 | 摘牌九十日、钱庄抵押、天机阁寻物 |
| 可见收益 | 人情簿条数、排名、师兄“真身”解封 |
| 嵌套层次 | 开局绝境（抵押）是阴谋；一集一案可重复；小满和师兄身份层层剥；私人谜团（她是什么）；世界观颠覆（公堂审天道）；换地图（巡回断案） |
| 灵魂 | 反常识命题：讨公道的自己是件物；伤口即能力：年轮；活着的在乎之人：五位师兄；代价：会变回木头 |
| 反派阶梯 | 账房 → 邻宗少主 → 榜阁执事 → 天机阁 |
| 合规 | 只判“还”不判生死；无血腥；未成年主角无危险模仿行为 |

## 七、风险与待验证
1. **差异是否被观众感知**：“公开升堂”和“判决生效”要在第 1 集前 30 秒就演出来，否则仍会被当成“听懂心声”。第 1 集开场必须先升堂、再解释。
2. **断案推理太绕会劝退下沉观众**：每案只留一个推理点，答案用画面揭晓（裂开、褪色），不靠台词解释。
3. **主角身份反转**放在第一季 E 段，太早会冲淡团宠，太晚怕观众没耐心；需测试。
4. 五岁主角的配音与台词分寸；“说谎咬舌头”不要做成自伤。
5. 宗门倒闭、团宠、师兄是题材共性，不是抄袭；上线前仍需法务和平台核对与已上榜作品的差异。
6. 评审团是 AI 模拟，不能替代小预算投流测试（建议用前 3 集测）。
