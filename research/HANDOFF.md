## 在本地运行工具
```bash
# 1. 把 35 本 txt 放进一个文件夹，比如 novels/
export NOVEL_DIR=novels
cd research/tools
mkdir -p books dl
python3 parse.py                 # 拆分章节，生成 books/<key>.json 和 books/<key>.chapters.jsonl
python3 analyze.py               # 每本书的量化数据，生成 books/<key>.metrics.json
python3 dump.py <key> ...        # 快速概览：简介、抽样标题、开篇 2 章
python3 prep.py <key> 12 "20,40,80"   # 深读素材：前 12 章全文 + 指定章节的开头 + 最后 2 章，生成 dl/deep_<key>.txt
```
`<key>` 是文件名的前 8 位。用这套命名的话，就是上传时自动生成的那段编号前缀；如果是本地自己命名的文件，就按文件名前 8 个字符匹配。

## 已知问题
- 《异兽迷城》导出时，章节标题和正文被拆成了两行，所以统计出的章节数是实际的两倍；
- 《神明降世》有多章被合并成了一章，所以章节数偏少；
- 人名识别没有用分词库，只是规则匹配，会混进少量噪音，写档案时需要手动剔除；
- 仓库推送到 GitHub 时一直报 403：Claude GitHub App 没有 Sg-fit/Hi 这个仓库的权限。
